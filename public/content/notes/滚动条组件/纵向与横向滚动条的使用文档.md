# ScrollWrapper 纵向与横向滚动条 使用文档

> 组件路径：`src/views/kongguJww/smartTechnology/components/common/ScrollWrapper.vue`

## 一、组件简介

`ScrollWrapper` 是一个**自绘滚动条**的滚动容器组件。

它弃用了 webkit 原生的 `::-webkit-scrollbar`（在 Electron 下存在绘制缓存 bug：鼠标移出后滑块不消失 / 一直显示），改为使用**绝对定位的 overlay 滑块**，显隐完全由 JS 控制，位置与尺寸随滚动实时同步。

主要特性：

- 支持 **横向滚动**（`type="horizontal"`，默认）与 **纵向滚动**（`type="vertical"`），两者用法完全一致。
- 滑块默认隐藏，鼠标进入容器时才显示（`mouseenter`），移出后隐藏（`mouseleave`），拖拽过程中保持显示。
- 横向模式下会把**竖向滚轮**转换为**横向滚动**。
- 自身无溢出，或已滚到边界后继续往外滚时，**不拦截滚轮事件**，交给外层容器滚动（避免滚动穿透问题）。
- 滑块支持鼠标拖拽。
- 暴露 `syncThumb()` 方法，供异步数据加载完成后主动重算滑块尺寸/位置。

## 二、Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `type` | `'horizontal' \| 'vertical'` | `'horizontal'` | 滚动方向。`horizontal` 横向滚动，`vertical` 纵向滚动。 |

### type 对应的容器样式差异

- **`horizontal`（横向）**
  - 容器 `flex-direction: row`，`overflow: auto hidden`，`white-space: nowrap`。
  - 固定高度 `144px`（`min-height: 144px`）。
  - 滚动条轨道覆盖在容器**底部**，高 `6px`。
- **`vertical`（纵向）**
  - 容器 `flex-direction: column`，`overflow: hidden auto`，`height: 100%`。
  - 高度撑满父容器，需父级有明确高度。
  - 滚动条轨道覆盖在容器**右侧**，宽 `6px`。

> 注意：容器默认带有 `gap: 12px` 与 `cursor: grab`。横向模式高度固定为 144px，如需自定义高度可在使用处通过 class 覆盖样式。

---

## 三、Emit

该组件**没有对外暴露任何自定义事件**（无 `emit`）。

内部使用了 `@mouseenter`、`@mouseleave`、`@wheel`、`@scroll`、`@mousedown` 等原生 DOM 事件来驱动滑块逻辑，均为组件内部消费，不向父组件透传。

---

## 四、暴露给外部调用的方法（defineExpose）

| 方法 | 参数 | 返回值 | 说明 |
| --- | --- | --- | --- |
| `syncThumb()` | 无 | `void` | 重新测量容器滚动状态，重算滑块的尺寸与位置。**典型场景**：异步数据加载完成、列表内容发生变化后，需要主动调用以保证滑块正确显示。 |

调用方式：通过模板 `ref` 获取组件实例后调用。

```ts
import ScrollWrapper from '../common/ScrollWrapper.vue';

const scrollWrapperRef = ref<InstanceType<typeof ScrollWrapper>>();

// 数据更新后（建议放在 nextTick 中，确保 DOM 已渲染）
nextTick(() => {
  scrollWrapperRef.value?.syncThumb();
});
```

## 五、示例用法

### 示例 1：横向滚动 + 数据更新后重算滑块（来自 `OrgsDown.vue`）

横向滚动是默认模式，无需传 `type`。异步接口返回数据后，在 `nextTick` 中调用 `syncThumb()` 重算滑块。

```vue
<template>
  <!-- orgList 为空 → 占位图；否则正常滚动卡片 -->
  <div v-if="!orgList.length" class="orgcard-empty">
    <img :src="zanwuImage" alt="暂无数据" class="zanwu-img" />
  </div>
  <scroll-wrapper v-else ref="scrollWrapperRef">
    <org-card-top
      v-for="item in orgList"
      :key="item.id"
      :item="item"
      :isActive="selectedRegions.includes(item.regionName)"
      @set-level="setLevelTop"
    />
  </scroll-wrapper>
</template>

<script lang="ts" setup>
  import { ref, nextTick } from 'vue';
  import ScrollWrapper from '../common/ScrollWrapper.vue';

  // 仅持有 ref，以便数据更新后重算滑块
  const scrollWrapperRef = ref<InstanceType<typeof ScrollWrapper>>();

  function fetchData() {
    // ...请求数据...
    nextTick(() => {
      scrollWrapperRef.value?.syncThumb();
    });
  }
</script>
```

### 示例 2：纵向滚动（来自 `DrillDown.vue`）

通过 `type="vertical"` 开启纵向滚动。父容器需有明确高度，组件高度撑满父级。

```vue
<template>
  <ScrollWrapper type="vertical" class="level3-list">
    <div
      v-for="(child, n) in item?.level3"
      :key="n"
      class="level3-item"
      :class="{ active: selectedType === child.title }"
      @click.stop="handleClick(child.title)"
    >
      <div class="title">{{ child.title }}</div>
      <BarProgress :data="child" />
    </div>
  </ScrollWrapper>
</template>

<script setup lang="ts">
  import ScrollWrapper from '../../components/common/ScrollWrapper.vue';
</script>
```

### 示例 3：横向滚动 + onMounted 初始化重算（来自 `MindMapContainer.vue`）

首屏挂载后，在 `nextTick` 中调用一次 `syncThumb()`，确保初次渲染时滑块正确。

```vue
<template>
  <div class="card-row">
    <scroll-wrapper ref="scrollWrapperRef">
      <CardComp
        v-for="m in metrics"
        :key="m.key"
        :iconKey="m.key"
        :data="m.card"
        :active="activeKey === m.key"
        @select="select(m.key)"
      />
    </scroll-wrapper>
  </div>
</template>

<script setup lang="ts">
  import { ref, onMounted, nextTick } from 'vue';
  import ScrollWrapper from '../../components/common/ScrollWrapper.vue';

  const scrollWrapperRef = ref<InstanceType<typeof ScrollWrapper> | null>(null);

  onMounted(() => {
    nextTick(() => {
      scrollWrapperRef.value?.syncThumb();
    });
  });
</script>
```

## 六、使用注意事项

1. **内容通过默认插槽传入**：直接把需要滚动的子元素放在 `<scroll-wrapper>...</scroll-wrapper>` 之间即可。
2. **异步数据务必调用 `syncThumb()`**：组件在鼠标进入容器时（`onWrapEnter`）会自动量一次尺寸，但若希望数据加载后立即有正确滑块（无需等待鼠标进入），需在 `nextTick` 中手动调用 `syncThumb()`。
3. **纵向模式需要父级有高度**：`vertical` 容器为 `height: 100%`，父容器无明确高度时不会出现滚动。
4. **横向默认高度 144px**：如不符合需求，通过外层 class 覆盖 `.scroll-container--horizontal` 的高度样式。
5. **滚动穿透已处理**：内容未溢出，或滚动到边界后继续往外滚，事件会放行给外层容器，无需额外处理。
6. **组件名称**：`name: 'ScrollWrapper'`，模板中可用 `<ScrollWrapper>` 或 `<scroll-wrapper>` 两种写法。

## 七、内部实现要点（便于维护）

- `barVisible`：鼠标是否在容器内，控制滑块显隐。
- `dragging`：是否正在拖拽滑块，拖拽时保持滑块显示。
- `hasOverflow`：内容是否超出（决定是否需要滚动条）。
- `thumbSize` / `thumbOffset`：滑块的长度与偏移，由 `syncThumb()` 根据 `clientSize / scrollSize / scrollPos` 计算，滑块最小长度 `30px`。
- 拖拽通过 `window` 上的 `mousemove` / `mouseup` 监听实现，组件卸载（`onBeforeUnmount`）时会清理监听，避免内存泄漏。

# TreeTable 可展开排序表格 使用文档

> 组件路径：`src/views/kongguJww/smartTechnology/components/clueMatrixAnalysis/TreeTable.vue`

## 一、组件简介

`TreeTable` 是基于 `ant-design-vue` 的 `a-table` 封装的**树形可展开 + 可排序**表格组件，面向智能科技（smartTechnology）模块的各类明细表场景。核心能力：

- **逐列层级展开**：通过「固定列（`fixedColumns`）」表头的 `+/-` 按钮逐级下钻，展开下一层数据（非 antd 原生 children 展开，而是按列字段逐层请求/渲染）。
- **列排序**：列头点击排序图标，升/降序切换，并据此请求数据。
- **两种数据来源**：
  - **内置查询**：不传 `dataSource`、不传 `promiseFunc` 时，组件根据 `tabType` 调用内置接口（线索明细/未下发/未建档/战败原因/新媒体矩阵）。
  - **外部托管**：传 `promiseFunc`（返回 Promise）或直接传 `dataSource`，由父组件提供数据。
- **多级表头**：`treeTableColumns` 支持 `children` 嵌套，渲染多级分组表头。
- **单元格合并**：固定列支持纵向合并（相同值自动合并）与横向合并（`merge` 字段指定跨列数）。
- **合计行高亮**：`rowType === 'total'` / `nodeType === 'TOTAL'` 的行整行高亮（绿底绿框）。
- **分页**：`total > pageSize` 时显示分页器。
- **行选择**：透传 `rowSelection` 给 `a-table`，可用于多选（如下拉表格选择器）。
- **列高亮**：`highCol` 命中的列单元格背景高亮。
- **单元格 Tooltip**：`isTooltip` 开启后单元格单行省略，悬浮显示完整内容（适配 scale 缩放容器坐标）。

## 二、Props

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `pageSize` | `Number` | `50` | 每页条数（也作为分页器的 `pageSize`）。 |
| `height` | `Number` | `250` | 表体纵向滚动高度（`scroll.y`）。`noScroll` 为 true 时忽略。 |
| `title` | `String` | `''` | 表格左上角标题，传空则不显示标题栏。 |
| `tabType` | `String` | `'1'` | 内置查询的业务类型：`1` 线索渠道明细 / `2` 未下发线索 / `3` 未建档 / `4` 战败原因 / `5` 新媒体矩阵。仅在走内置查询时生效。 |
| `promiseFunc` | `Function` | `undefined` | 外部数据函数。返回 `Promise<{ tableData, totalNum }>` 时由父组件托管数据；返回 `false` 时回落到内置查询。传入后排序/翻页会 `emit` 给父组件。 |
| `treeTableColumns` | `TreeTableColumn[]` | `[]` | 数据列配置（非固定列）。支持 `children` 多级表头。 |
| `fixedColumns` | `Column[]` | `[]` | 固定列（通常 `fixed: 'left'`），承载层级展开（`expandable`）、合并（`merge`）等逻辑。 |
| `dataSource` | `Record<string, any>[]` | `undefined` | 外部直接传入的表格数据。**传入后优先使用，不走内部查询**。 |
| `rowSelection` | `Object` | `undefined` | 透传给 `a-table` 的 `row-selection`（行选择配置）。 |
| `rowKeyField` | `String` | `''` | 外部数据行唯一键字段名（如 `'fieldName'`）。传入后 `getRowKey` 优先使用该字段。 |
| `noScroll` | `Boolean` | `false` | 关闭表体纵向滚动（不设 `scroll.y`）。用于 scale 缩放容器内避免表头与首行错位、列竖线断裂。 |
| `highCol` | `string[]` | `[]` | 需高亮背景的列 key 列表（背景 `#F4F7FC`）。 |
| `isTooltip` | `Boolean` | `false` | 开启后单元格单行省略，悬浮显示完整内容（灰底白字）。 |

### 列配置类型

**Column（固定列 `fixedColumns`）**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `key` | `string` | 列字段（对应数据 `record[key]`）。 |
| `title` | `string` | 列标题。 |
| `width` | `number \| string` | 列宽。 |
| `sortable` | `boolean` | 是否可排序（显示排序图标）。 |
| `expandable` | `boolean` | 是否可层级展开（表头显示 `+/-`）。 |
| `merge` | `string` | 横向合并：指向某字段，单元格按该字段值跨列合并（如 `cityColSpan`）。 |
| `color` | `string` | 单元格文字颜色。 |
| `unit` | `string` | 单元格数值后缀（如 `%`）。 |
| `isTextCenter` | `boolean` | 单元格内容居中。 |
| `isSlot` | `boolean` | 自定义单元格：开启后该列不渲染默认文本，改用同名插槽 `#<key>` 渲染（见「七、插槽」）。 |
| `isCount` | `boolean` | 默认走 `getCount` 数值格式化；置 `true` 时直接取原值拼接 `unit`（不做千分位等格式化）。 |
| `fixed` | `'left' \| 'right'` | 固定方向（透传 a-table）。 |

**TreeTableColumn（数据列 `treeTableColumns`）**

字段与 Column 基本一致，额外支持：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `key` | `string?` | 叶子列必须带 `key`；分组列（带 `children`）可不带 `key`。 |
| `children` | `TreeTableColumn[]` | 子列，用于多级表头嵌套。 |

> 说明：叶子列的 `key` 需与接口返回字段一一对应（组件通过 `record[column.key]` 取值）。

## 三、Emit

| 事件 | 参数 | 触发时机 | 说明 |
| --- | --- | --- | --- |
| `change` | `(page: number)` | 翻页时 | **仅当传入 `promiseFunc` 时触发**。未传 `promiseFunc` 时翻页走组件内部 `initList`，不 emit。父组件应据此更新 `pageNum` 并刷新数据。 |
| `sort` | `(sortState: Record<string, string>)` | 列排序时 | **仅当传入 `promiseFunc` 时触发**。emit 同步通知父组件最新排序状态后，组件自身随即触发数据刷新。父组件应只记录排序状态，**不要**在此回调里调用 expose 的 `getList`/`initList`（会重置 sortState）。 |

---

## 四、暴露给外部调用的方法（defineExpose）

| 方法 | 参数 | 说明 |
| --- | --- | --- |
| `initList()` | 无 | **重置并重新加载**。会重置：`pageNum=1`、清空排序 `sortState`、清空展开状态 `dataMap`、`displayField` 复位到第一层、清空 `headerFields`，然后请求数据。**典型场景**：筛选条件变化后重新查询。 |
| `getList()` | 无 | **保持当前状态重新加载**（不重置分页/排序/展开）。**典型场景**：父组件 `promiseFunc` 模式下翻页、外部条件变化后静默刷新。 |

调用方式：

```ts
const treeTableRef = ref<InstanceType<typeof TreeTable> | null>(null);

// 筛选变化：重置并重查
treeTableRef.value?.initList();

// 静默刷新：保留分页/排序
treeTableRef.value?.getList();
```

## 五、依赖约定（inject）

组件内部通过 `inject('currentQueryParams')` 读取查询参数（一个 `Ref<Partial<FilterQueryParams>>`）。**走内置查询（`tabType` 模式）时，祖先组件必须 `provide('currentQueryParams', ...)`**，否则内置接口取不到筛选条件。

```ts
// 页面级 provide
const currentQueryParams = ref<Partial<FilterQueryParams>>({});
provide('currentQueryParams', currentQueryParams);
```

> 若使用 `dataSource` 直接传数据，则不依赖该 inject。

## 六、示例用法

### 示例 1：内置查询 + 多级固定列展开（来自 `ClueMatrixAnalysis.vue`）

页面 `provide` 查询参数，筛选后调用 `initList()` 重查。固定列逐级可展开。

```vue
<template>
  <tree-table
    :height="300"
    ref="treeTableRef"
    :treeTableColumns="treeTableColumns"
    :fixedColumns="fixedColumns"
  />
</template>

<script setup lang="ts">
  import { ref, provide, nextTick } from 'vue';
  import TreeTable from '../components/clueMatrixAnalysis/TreeTable.vue';

  const currentQueryParams = ref({});
  provide('currentQueryParams', currentQueryParams); // 内置查询必需

  const treeTableRef = ref<InstanceType<typeof TreeTable> | null>(null);
  const handleFilterQuery = (params) => {
    currentQueryParams.value = params;
    nextTick(() => treeTableRef.value?.initList()); // 筛选后重置并重查
  };

  const fixedColumns = ref([
    { fixed: 'left', key: 'leadSource', title: '来源', width: 110, sortable: true, expandable: true },
    { fixed: 'left', key: 'firstLevelSource', title: '一级来源', width: 150, sortable: true, expandable: true },
    // city 列横向合并：按 cityColSpan 字段跨列
    { fixed: 'left', key: 'city', merge: 'cityColSpan', title: '城市', width: 110, sortable: true, expandable: true },
    { fixed: 'left', key: 'dealer', merge: 'dealerColSpan', title: '经销商', width: 130, sortable: true, expandable: false },
  ]);
  const treeTableColumns = ref([
    { key: 'clue', title: '原始线索数', width: 140, sortable: true },
    { key: 'issueRate', title: '下发率', width: 115, sortable: true },
  ]);
</script>
```

### 示例 3：外部托管数据 promiseFunc + change/sort（来自 `CompFifth.vue`）

`promiseFunc` 返回 `Promise<{ tableData, totalNum }>` 时数据由父组件托管；翻页/排序通过 `@change`/`@sort` 回传。

```vue
<template>
  <tree-table
    :pageSize="10"
    :tabType="typeMap[props.tabType]"
    :title="props.titleTable"
    :promiseFunc="promiseFunc"
    ref="treeTableRef"
    :tree-table-columns="treeTableColumns"
    :fixed-columns="fixedColumns"
    @change="handleChangePage"
    @sort="handleSort"
  />
</template>

<script setup lang="ts">
  const treeTableRef = ref<InstanceType<typeof TreeTable>>();
  const pageNum = ref(1);
  const sortOrders = ref<Record<string, string>>({});

  function handleChangePage(page: number) {
    pageNum.value = page;
    treeTableRef.value?.getList(); // 翻页：保留状态刷新
  }
  function handleSort(sortState: Record<string, string>) {
    // 只记录排序状态，数据刷新由 TreeTable 自身触发。
    // 切勿在此调用 expose 的 getList/initList（会重置 sortState）。
    sortOrders.value = sortState;
  }
  function promiseFunc() {
    if (props.tabType === '7') {
      return queryIntentionOrderData({
        ...currentQueryParams.value,
        pageNum: pageNum.value,
        pageSize: 10,
        sortOrders: Object.values(sortOrders.value),
      }).then((res) => ({
        tableData: res.data?.amountTable?.rows || [],
        totalNum: res.data?.page?.total || 0,
      }));
    }
    return false; // 返回 false → 回落到内置查询
  }
</script>
```

## 七、插槽（Slot）

`treeTableColumns` 中某列配置 `isSlot: true` 时，该列**不再渲染默认文本**，而是渲染一个 `name` 等于该列 `key` 的具名插槽，由父组件自定义单元格内容（标签、按钮、图标、序号等）。

### 用法

```vue
<tree-table :tree-table-columns="cols">
  <template #<列key>="{ record, index }">
    <!-- 自定义内容 -->
  </template>
</tree-table>
```

### 作用域参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `record` | `Record<string, any>` | 当前行数据对象（即 `tableData` 的一项）。 |
| `index` | `number` | 当前行在数据源中的索引（从 0 开始）。 |

> 注意：`index` 是数据源内的行索引，分页/排名等场景若需「全局序号」需自行结合 `pageNum`、`pageSize` 换算（见示例 7 的 `rankNo`）。

### 约定与注意

1. **插槽名必须等于列的 `key`**：组件内部以 `column.key` 作为 `<slot :name>`，名称不一致则插槽不生效，单元格为空。
2. **`isSlot` 列的取值逻辑被跳过**：`unit`、`isCount`、`getCount` 数值格式化、`isTooltip` 省略等均不作用于插槽列，内容完全由插槽决定。
3. **固定列（`fixedColumns`）不支持插槽**：插槽仅对 `treeTableColumns` 生效；固定列承载层级展开/合并逻辑，按默认文本渲染。
4. **样式作用域**：插槽内容写在父组件模板里，样式也由父组件提供（`scoped` 样式可直接命中插槽内元素）。

## 八、使用注意事项

1. **内置查询必须 `provide('currentQueryParams')`**：走 `tabType` 内置接口时，祖先需提供该注入，否则查询参数为空。
2. **数据来源优先级**：`dataSource`（直接数据） > `promiseFunc`（返回 Promise） > 内置 `tabType` 查询。`promiseFunc` 返回 `false` 时回落到内置查询。
3. **筛选用 `initList`，翻页/刷新用 `getList`**：`initList` 会重置分页、排序、展开状态；`getList` 保留当前状态。
4. **`promiseFunc` 模式下排序回调不要再调 expose 方法**：`@sort` 里只记录 `sortState`，刷新由组件自身完成；调用 `getList`/`initList` 会把排序状态重置。
5. **scale 缩放容器内开启 `noScroll`**：若表格位于带 `transform: scale` 的容器，开启 `noScroll` 可避免表头/首行错位与列竖线断裂（代价是失去表体内滚动）。
6. **多级表头补边框**：`children` 多级表头的分组单元格右/下边框默认不显示，需要时在使用处用 `:deep(.ant-table-thead th)` 补 `border`（见 ChannelDetail 样式）。
7. **合并依赖数据字段**：横向合并 `merge` 指向的字段（如 `cityColSpan`）需由接口数据提供跨列数；纵向合并按固定列相邻同值自动计算。
8. **组件名写法**：模板中可用 `<TreeTable>` 或 `<tree-table>`。

## 九、特殊行类型约定

| 字段 | 取值 | 效果 |
| --- | --- | --- |
| `record.rowType` | `'total'` | 合计行：第一固定列横向合并整个固定列区，不参与纵向合并。 |
| `record.rowType` | `'subtotal'` | 小计行：配合列的 `merge` 时不显示展开按钮。 |
| `record.nodeType` | `'TOTAL'` | 整行高亮（绿底 + 绿色边框）。 |
| `record.nodeKey` | `string` | 层级展开的节点唯一标识（用 `\|` 分隔层级）。 |
| `record.__rowKey` | 内部生成 | 组件为树形数据自动打标的稳定唯一 rowKey。 |

# wiki

个人笔记库博客网站：学习笔记、前端项目、代码片段的总结与展示。

技术栈：React 18 + Vite + Ant Design 5 + React Router 6，支持亮 / 暗色模式。

## 开发

```bash
npm install
npm dev        # 本地开发
npm run build  # 类型检查 + 生产构建
```

## 规划

- **笔记**：Markdown 文档，分类 / 标签筛选，目录导航
- **项目**：可运行的完整前端项目，在线演示 + 源码浏览（文件树 + 语法高亮）
- **代码片段**：按语言分组，语法高亮与一键复制
